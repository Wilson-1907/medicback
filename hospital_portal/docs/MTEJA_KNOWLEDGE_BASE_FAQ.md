# Afya Rafiki — Mteja knowledge base (index)

Use **two separate knowledge bases** in Mteja — one per language:

| Language | File | Mteja knowledge base name |
|----------|------|---------------------------|
| **English** | [`MTEJA_KNOWLEDGE_BASE_EN.md`](MTEJA_KNOWLEDGE_BASE_EN.md) | Afya Rafiki — English |
| **Kiswahili** | [`MTEJA_KNOWLEDGE_BASE_SW.md`](MTEJA_KNOWLEDGE_BASE_SW.md) | Afya Rafiki — Kiswahili |

Each file has **25 Q&A pairs** (programme overview, HELP menu, FAQs, results, appointments, urgent, registration).

**WhatsApp templates:** [`WHATSAPP_MESSAGE_TEMPLATES.md`](WHATSAPP_MESSAGE_TEMPLATES.md)  
**Go-live:** [`MTEJA_WHATSAPP_GO_LIVE.md`](MTEJA_WHATSAPP_GO_LIVE.md)

## Quick steps in Mteja

1. **Knowledge base** → Create **Afya Rafiki — English** → import from `MTEJA_KNOWLEDGE_BASE_EN.md`
2. **Knowledge base** → Create **Afya Rafiki — Kiswahili** → import from `MTEJA_KNOWLEDGE_BASE_SW.md`
3. Link each KB to your WhatsApp chatbot (or language routing)
4. Keywords: **HELP** / **MSAADA** → menu · **DOCTOR** / **DAKTARI** → provider handoff
